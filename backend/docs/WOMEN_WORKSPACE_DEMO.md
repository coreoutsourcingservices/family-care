# Women's workspace fixes and sample data

- The calendar closes after a successful save. It stays open with entered text after a failed save; duplicate submissions are disabled while saving. Navigating to another section closes calendar/search.
- Doctor search uses one focus border. Page search closes on Escape or focus leaving its field/results.
- Directory requests send `module=women` and selected `concern`. Without explicit search, gynecology/obstetrics/reproductive specialties are shown; hormonal concerns also include endocrinology; fertility adds fertility/IVF; general wellness can include general/family/internal medicine. Explicit doctor name/specialty search returns matching approved clinicians. Approval checks and rating order remain in place. Older responses cannot replace newer search results.
- Women's report uploads now use the existing authorized upload controller, including its 10 MB file limit and multipart checks. Previously the women's route inherited the 16 KB general request limit.
